# ExternalGoogleFileWarning

This simple Chrome extension displays a popup inside Chrome whenever a user:
- opens an externally owned Google Drive file
- opens any Google Form

Notes:
- in the case of Google Drive files, ensure you have <i><a href="https://admin.google.com/ac/managedsettings/55656082996/sharing">Apps > Google Workspace > Drive and Docs > Sharing settings</a> > Highlight external files</i> set to <b>ON</b> for all users
- in the case of Forms, the popup will display where the Form is owned (your domain, another domain, or outside your domain)
